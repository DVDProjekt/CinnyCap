# CinnyCap

A fork and upgraded version of [Cinny](https://github.com/cinnyapp/cinny), focused on improving the overall user experience, especially for Arabic and Persian users.

CinnyCap is provided as a **pre-built version of Cinny** with a collection of interface, typography, search, and theme improvements. It follows the same general usage model as Cinny, so users familiar with Cinny can use CinnyCap in the same way.

For general usage and Cinny-related documentation, please refer to the original [Cinny repository](https://github.com/cinnyapp/cinny).

---

## Features

### Arabic & Persian Improvements

CinnyCap includes several improvements aimed at providing a better experience for users who communicate in Arabic and Persian.

* Improved compatibility with Arabic and Persian text.
* Better handling and presentation of Arabic/Persian content throughout the interface.
* An updated Arabic-friendly font for improved readability.
* General UI adjustments that make Arabic and Persian conversations feel more natural and comfortable.

### Improved Chat & Message Interface

The chat and message interface has been refined with a number of visual and usability improvements.

* Improved message presentation.
* Refined chat interface layout.
* Better visual consistency across chat elements.
* Small interface adjustments for a cleaner and more comfortable messaging experience.

### Improved User Search

CinnyCap includes an improved user search experience.

The search functionality is still under development and has **not yet reached a fully stable state**. At the moment, the search system primarily relies on the server name when finding users.

This feature may continue to evolve in future versions.

### New Themes

CinnyCap adds several new themes to give users more control over the appearance of the application.

Included themes include:

* **Ocean Dark** — A dark theme with an ocean-inspired appearance.
* **Neon** — A more vibrant theme with a modern neon-inspired interface.
* **SoftBlue** — A softer blue theme designed for a calm and comfortable appearance.

Additional visual refinements have also been made across the interface to provide a more consistent experience between themes.

### End-to-End Encryption Interface

CinnyCap includes some changes to the **End-to-End Encryption (E2EE)** interface.

These changes are **visual and interface-only**. They do not introduce changes to the underlying encryption behavior or alter the way End-to-End Encryption works compared to Cinny.

The purpose of these changes is to provide a refined user interface and improve the overall presentation of E2EE-related elements while preserving the existing Cinny user experience.

### Other Improvements

CinnyCap also contains various smaller improvements and visual refinements throughout the application.

These include minor interface adjustments, styling changes, typography refinements, and other quality-of-life improvements intended to make the overall experience cleaner and more polished.

## Usage

CinnyCap is distributed as a **pre-built version**.

There is no separate usage model or workflow to learn. If you already know how to use Cinny, you can use CinnyCap in the same way.

For information about using Cinny, Matrix, homeservers, rooms, accounts, and other general functionality, refer to the official [Cinny documentation and repository](https://github.com/cinnyapp/cinny).

---

## Based on Cinny

CinnyCap is a fork of [Cinny](https://github.com/cinnyapp/cinny), an open-source Matrix client focused on providing a simple, elegant, and secure interface.

CinnyCap builds on the Cinny experience while introducing additional UI improvements, themes, typography changes, and enhancements focused particularly on Arabic and Persian language support.

All original Cinny functionality remains available unless otherwise affected by the changes described above.
